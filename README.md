## ✨ المميزات
* **أوامر تفاعلية:** يدعم أكثر من 30 أمراً تشمل (الذكاء الاصطناعي، تحميل الأغاني، وصناعة الأغلفة).
* **لوحة تحكم الويب:** واجهة ويب لمراقبة حالة البوت، وقت التشغيل (Uptime)، وسجلات وحدة التحكم (Logs) في الوقت الفعلي.
* **نظام إشعارات المطور:** إرسال رسائل "عامة" لجميع المجموعات مع دعم كامل للمرفقات (صور وفيديو).
* **معالجة الأحداث:** رسائل ترحيب ووداع قابلة للتخصيص عند دخول أو خروج الأعضاء.
* **استقرار عالٍ:** يعمل بنظام PM2 لضمان بقاء البوت متصلاً 24/7.

## 🛠️ المتطلبات الأساسية
* **Node.js:** الإصدار 20 أو أحدث.
* **PM2:** لإدارة العمليات في الخلفية.
* **APPSTATE_JSON:** متغير بيئة سري يحتوي على جلسة Facebook؛ لا تضعه في GitHub.

## 🚀 التثبيت
```bash
# استنساخ المستودع
git clone [https://github.com/omarfoks40-svg/eva.git](https://github.com/omarfoks40-svg/eva.git)
cd eva

# تثبيت التبعيات
npm install

# تثبيت PM2 عالمياً
npm install -g pm2


## Render

1. أنشئ Web Service من هذا المستودع باستخدام ملف render.yaml.
2. أضف السر APPSTATE_JSON بقيمة app state الجديدة، ولا تضعها في GitHub.
3. أضف OPENAI_API_KEY لتفعيل تحليل الصور وتوليد الأكواد.
4. استخدم الأمر npm start؛ صفحة الفحص هي /.
